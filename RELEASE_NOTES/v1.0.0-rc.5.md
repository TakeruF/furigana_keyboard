# Furigana Keyboard v1.0.0-rc.5

キーボードの切り替えと、パスワード欄での扱いを整えた正式版候補の第5版です。

## 主な変更

- 地球儀キーをタップすると次のキーボードへ直接切り替わるように変更。長押しで従来のキーボード選択画面を表示
- パスワード欄では候補表示、辞書検索、読み推測、未確定文字を使わず、1文字ずつ確定する方式に変更
- 入力内容を端末内に保存しない方針を維持したうえで、変換中に一時保持していた候補も入力欄を離れた時点で破棄
- 横向きでも入力欄が全画面の簡易入力画面に置き換わらず、入力先のアプリが見えたままになるよう変更
- 未確定文字のカーソル移動、部分変換、1文字削除が見た目どおりの単位で動作するよう改善
- 手書き認識の候補順を整理し、認識した字が候補から外れないよう改善
- 読み辞書は検証済みの完全版を優先して使用

## リリース候補版について

- 正式公開前の確認用ビルドです。重要な文章では変換結果を確定前に確認してください。
- 直接配布版の更新確認にはネットワーク接続が必要です。入力文字や手書きデータは更新確認に送信されません。

## 動作環境

- Android 7.0以降
- APKを直接インストールする場合、端末側で配布元からのインストール許可が必要になることがあります。
